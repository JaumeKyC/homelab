
# homelab
Esto es  un laboratorio personal donde aprendo y mejoro mis habilidades como devops.

## La aplicación
La idea es crear una API en Python con PostgreSQL.
Primera idea: Una API para registrar y gestionar servidores, aplicaciones y servicios.

Funcionalidades:
- Registrar servidores (nombre, IP, entorno y sistema operativo).
- Registrar servicios desplegados en cada servidor.
- Consultar su estado (disponible, caído, mantenimiento).
- Registrar incidencias.
- Consultar históricos de disponibilidad.

## Etapas
0. **Laboratorio:** WSL2, Docker Engine, Git y GitHub
1. **Docker:** contenedores, imágenes y Docker Compose
2. **CI/CD:** GitHub Actions y Jenkins
3. **Kubernetes:** clúster local con kind y Helm
4. **Terraform y AWS:** infraestructura como código
5. **GitOps y observabilidad:** Argo CD, Prometheus y Grafana
